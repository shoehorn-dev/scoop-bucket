# Shoehorn Scoop Bucket

Scoop bucket for the [Shoehorn CLI](https://github.com/shoehorn-dev/cli).

## Usage

```powershell
scoop bucket add shoehorn https://github.com/shoehorn-dev/scoop-bucket
scoop install shoehorn
```

## Update

```powershell
scoop update shoehorn
```

## Manifest

Updated automatically on each CLI release via GitHub Actions.
